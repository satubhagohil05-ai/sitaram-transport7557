SITARAM TRANSPORT — Netlify Ready

1. Open https://app.netlify.com/drop
2. Drag the ENTIRE contents of this folder into the Drop area.
3. Netlify will publish the PWA and give you an HTTPS URL.
4. Open that URL on Android Chrome.
5. Use Chrome menu → Add to Home screen / Install app.

Important:
- Keep index.html, sw.js, manifest.webmanifest, _headers, netlify.toml and the icons folder together.
- This app stores accounting data in the browser's local storage. Data does not automatically sync between different phones/browsers.
