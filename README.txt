SITARAM TRANSPORT PWA

Files:
- index.html: main application
- manifest.webmanifest: PWA manifest
- sw.js: offline service worker
- icons/: app icons

Install:
1. Host this folder on HTTPS (or localhost).
2. Open index.html through the hosted URL in Chrome/Edge on Android.
3. Use the Install prompt or browser menu > Add to Home screen / Install app.

Note: Service workers and PWA installation generally require HTTPS (localhost is also allowed). Opening index.html directly as file:// will not provide full PWA installation/offline behavior.
